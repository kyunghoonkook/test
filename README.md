# Mobile App Layout Project

모바일 앱의 기본 레이아웃을 구현한 React 프로젝트입니다. 카테고리 간 슬라이드 전환, 배너 캐러셀, 무한 스크롤 등의 핵심 기능을 포함하고 있습니다.

## 주요 기능

1. **카테고리 네비게이션**
   - 상단 탭 메뉴를 통한 카테고리 전환
   - 좌우 슬라이드로 카테고리 전환
   - 부드러운 전환 애니메이션

2. **배너 슬라이더**
   - 자동 순환되는 배너
   - 배너 인디케이터
   - 외부 링크 연동

3. **콘텐츠 리스트**
   - 무한 스크롤 구현
   - 카테고리별 독립적인 스크롤 상태
   - 로딩 상태 표시

4. **기타 기능**
   - 실시간 시계 표시
   - 스크롤 탑 버튼
   - 반응형 레이아웃

## 설치 및 실행

```bash
# 프로젝트 클론
git clone [repository-url]

# 디렉토리 이동
cd [project-directory]

# 의존성 설치
npm install

# 개발 서버 실행
npm start
```

## 사용된 기술

- React
- styled-components
- JavaScript ES6+

## 프로젝트 구조

```
src/
  ├── components/
  │   └── MobileApp.jsx    # 메인 컴포넌트
  ├── App.js
  └── index.js
```

## 주요 컴포넌트

### MobileApp.jsx
- 앱의 메인 컴포넌트
- 상태 관리 및 이벤트 핸들링
- styled-components를 사용한 스타일링

## 구현된 요구사항

1. 카테고리 간 이동
   - 탭 메뉴 클릭
   - 좌우 슬라이드 터치

2. 배너 영역
   - 최소 3개의 배너
   - 무한 루프 동작
   - 외부 링크 이동

3. 리스트뷰
   - 무한 스크롤
   - 로딩 상태 표시
